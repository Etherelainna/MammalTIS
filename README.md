# MammalTIS

MammalTIS is a comprehensive database of translation initiation sites (TISs) in humans and mice. It integrates publicly available translation initiation sequencing (TI-seq) datasets and provides TIS annotations, supporting evidence, and interactive tools for exploring translation initiation.

**Database:** https://lmmd.ecust.edu.cn/MammalTIS/

## Repository Overview

This repository provides the computational scripts used for TIS characterization in MammalTIS, along with related quality control reference materials.
